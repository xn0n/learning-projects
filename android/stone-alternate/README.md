## Инструменты и открытие

**Язык:** Java / Android. **Проект:** Gradle / Android Studio.

Android Studio, Android SDK, JDK и совместимый Gradle.

Откройте папку в Android Studio и настройте SDK/JDK локально. Версии плагина, SDK и Gradle смотрите в build/settings-файлах и gradle/wrapper/gradle-wrapper.properties.

Gradle wrapper JAR и локальный SDK path исключены из этой публикации. При необходимости восстановите wrapper собственными инструментами. Растровые drawable/mipmap-ресурсы также исключены: исходные ссылки на них могут потребовать добавления собственных разрешённых изображений до сборки.
