# codewars

**Черновик упражнения с вводом и указателем.**

Учебная работа: сохранён самостоятельный пример или отличающаяся версия исходников. Ниже описан фактический состав кода; результаты сборки и успешного запуска не заявляются.

## Что сделано

- Цикл ввода чисел и накопление суммы.
- Попытка выделения и освобождения динамической памяти.

В .resx сохранена только структура без data/metadata; поэтому локализованные и графические ресурсы могут потребовать восстановления из собственных разрешённых материалов. В исходнике new int(nums) создаёт один объект, затем память используется как массив и освобождается delete[]. Это известная ошибка черновика; безопасный запуск не заявляется.
