# learning

**Преобразования между символом и числом.**

Учебная работа: сохранён самостоятельный пример или отличающаяся версия исходников. Ниже описан фактический состав кода; результаты сборки и успешного запуска не заявляются.

## Что сделано

- Присваивание целого значения переменной char.
- Получение числового кода символьного литерала.
- Вывод результата в консоль.
