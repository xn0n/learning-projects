# uchebka

**Набор базовых C++ упражнений.**

Учебная работа: сохранён самостоятельный пример или отличающаяся версия исходников. Ниже описан фактический состав кода; результаты сборки и успешного запуска не заявляются.

## Что сделано

- Массивы, функции и классы.
- Разные учебные точки входа main1–mainN.
- Отдельные эксперименты с вводом и игровой логикой.
