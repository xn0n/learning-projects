# Calculator · вложенная версия

Отличающаяся реализация калькулятора на C#/WinForms. Основная логика: Forms/FormMain.cs; проект открывается через Calculator.sln. Это сохранённая учебная версия; сборка и выполнение не проверялись.

Локальные данные, бинарные/IDE-артефакты и непроверенные ресурсы исключены. См. [общие ограничения](../README.md).
