# menushka

**Учебное меню задач, фигур и кодирования.**

Учебная работа: сохранён самостоятельный пример или отличающаяся версия исходников. Ниже описан фактический состав кода; результаты сборки и успешного запуска не заявляются.

## Что сделано

- Меню заданий первого и второго семестра.
- Операции с фигурами и рисованием.
- Битовые маски, кодирование Caesar и файловые операции.

## Инструменты и открытие

**Язык:** C++. **Проект:** Visual Studio / MSBuild.

Windows, Visual Studio с Desktop development with C++.

Откройте соответствующий .sln в Visual Studio. Это исторические проекты: доступность выбранного toolset и targeting pack необходимо проверить на своей машине. Если требуется retargeting, выполните его в собственной копии.

## Статус и ограничения

**Статически подготовлено; не собрано и не запускалось.** Проверка XML-конфигурации не подтверждает правильность алгоритмов, доступность всех зависимостей или работу интерфейса.

Исключены локальные IDE-файлы, бинарные результаты, документы, данные и фотографии. В .resx сохранена только структура без data/metadata; поэтому локализованные и графические ресурсы могут потребовать восстановления из собственных разрешённых материалов. Персональные пути и контакты обезличены только в опубликованной копии.

Абсолютные файловые пути заменены относительным examples/local-input.txt. Исходные входные файлы не включены; создайте свои учебные данные перед запуском.
