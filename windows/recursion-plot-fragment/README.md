# Project2

**Фрагмент рекурсивных вычислений и графиков.**

Учебная работа: сохранён самостоятельный пример или отличающаяся версия исходников. Ниже описан фактический состав кода; результаты сборки и успешного запуска не заявляются.

## Что сделано

- NextRec и NextRec2 сохраняют последовательность и сумму.
- DrawGraf, DrawAxisX и DrawAxisY строят график.
- Методы MyForm используют C++/CLI и WinForms.
